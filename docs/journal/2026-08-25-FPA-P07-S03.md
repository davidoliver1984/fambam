# FPA-P07-S03 — Event contributions

## Outcome

Event Albums reuse the existing Album contribution workflow exactly as decided
by ADR-0009 §13. No new production branch or Event-specific upload endpoint was
needed: `Album.event_id` remains authorization-inert, while
`AlbumPolicy::contribute`, `MediaUpload.target_album_id` and
`AlbumContributionFinalizer` continue to govern contribution.

## Boundary review

The stage had no implementation blocker. Member contribution continues to use
the fixed `family_space` Album rule, and Contributor contribution continues to
require a live `AlbumGrant.can_contribute`. Guest participation, admission,
delivery and conversational authority remain wholly deferred to FPA-P07-S04.

## Changes

- Added backend coverage for direct Member contribution and grant-scoped
  Contributor upload finalisation against an Event-linked Album.
- Made the existing frontend contribution-control test explicitly exercise an
  Event-linked Album returned to a Contributor.
- Expanded the implementation guide with the bounded S03 objective, rationale,
  verification and commit boundary.
