## How the system works

The root Makefile is the developer command surface. Foundation checks delegate
to `scripts/check_foundation.py`, which validates JSON, Markdown formatting,
local documentation links and the accepted repository scaffold. Application
commands remain unavailable until the corresponding services exist and exit
with a clear explanation instead of reporting false success.

GitHub Actions runs the same `make foundation-check` command used locally, so
local and continuous-integration validation share one entry point.
