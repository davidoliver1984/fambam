# FPA-P11-S04 — Combined filters and saved views

## Session objective

Complete the accepted structured filter set and add creator-private saved
searches with tenant integrity, execution-time authorization revalidation,
Person-merge integration and Family Space teardown.

## Work completed

- Added authorized Album, tag, uploader and visibility filters alongside the
  existing Person, Event and historical-date criteria.
- Added `saved_searches` and `saved_search_people` with forced RLS,
  tenant-consistent composite foreign keys and relational Person references.
- Added creator-private saved-search CRUD and execution through the existing
  bounded typed search service.
- Added execution-time revalidation for every referenced Person, Event, Album,
  tag and uploader.
- Integrated saved Person filters with merge collision handling, snapshot
  capture and guarded reversal.
- Added explicit Family Space teardown and a functional typed TanStack Query
  interface for saving, running, replacing and deleting searches.

## Decisions

- Saved filter JSON is schema-versioned and contains no Person identifiers.
- Uploader suggestions derive only from Photos the actor can already see and
  therefore do not create a separate family-member directory surface.
- If every stored reference becomes unavailable, execution returns bounded
  empty result groups instead of broadening into an unfiltered archive query.
