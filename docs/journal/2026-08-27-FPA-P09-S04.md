# FPA-P09-S04 — Local face-analysis provider

## Session objective

Implement the real pinned local provider, complete the model/licensing record,
exercise the provider directly against the private S01 benchmark and calibrate
the S03 safety defaults without beginning queued processing.

## Work completed

- Pinned InsightFace 1.0.1, ONNX Runtime 1.29.0 and benchmark-only psutil 7.1.0.
- Downloaded the official `buffalo_l` v0.7 archive to the gitignored local
  model directory, matched its official archive hash, recorded all five file
  hashes and made provider construction verify them before model loading.
- Added a strict `InsightFaceProvider` which maps native inference into the
  provider-neutral `DetectedFace` contract and fails closed on malformed or
  non-finite provider output.
- Added direct private benchmark and CPU/CoreML parity scripts whose persisted
  local evidence deliberately excludes biometric vectors and coordinates.
- Chose threshold 0.6 after a bounded three-threshold count comparison and
  recorded the resulting logical configuration hash.
- Reduced the untrusted result-artifact ceiling from 8 MiB to 4 MiB using the
  measured serialized result sizes while retaining the existing structural
  ceilings.
- Added the read-only local model mount and native OpenCV libraries required
  for the Linux image-analysis container.

## Licensing record

The installed InsightFace package states that its Python code is MIT-licensed
and its provided pretrained models are non-commercial research only. The
official model archive contains five ONNX files but no embedded licence file;
that absence and the official upstream model-zoo restriction are recorded
explicitly in `docs/face-analysis/MODEL_LICENSING.md`. The current private,
non-commercial evaluation remains within the accepted assumption. Commercial
deployment or distribution remains a mandatory re-review trigger.

## Private evidence

The final Apple Silicon CPU run analyzed all 38 private assets directly. It
recorded 93 detections against 79 annotated visible faces, with 30 exact-count,
two under-count and six over-count images. This count-only corpus cannot prove
specific false-positive locations and is not used for identity accuracy.

Hot inference measured 66.856 ms median, 132.988 ms p95 and 141.732 ms maximum.
Model construction measured 365.652 ms, first inference warm-up 173.802 ms,
observed peak RSS 1,093,976,064 bytes and maximum result size 67,869 bytes.

CPU/CoreML parity on three representative assets produced the same face counts
and logical configuration identity. Minimum embedding cosine was
0.9992794022265646, with sub-pixel geometry deltas. The backend-exclusion rule
therefore remains supported by measured evidence.

The evidence calibrates S05's initial operational settings to 30-second queue
visibility, five receives, a 20-second worker inference timeout, five-minute
attempt staleness, three attempts per run, 60-minute service authorities and a
2 GiB single-inference worker. S05 owns applying and verifying those values.
