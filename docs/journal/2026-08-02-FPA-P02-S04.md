## Key implementation notes

Laravel's stock compromised-password verifier already sends the HIBP
`Add-Padding` header and fails open, but defaults to a 30-second timeout and
reports the caught exception, whose request URL contains the password-derived
SHA-1 prefix. The application replaces only that verifier contract with a
1.5-second implementation that records a provider/outcome warning without the
exception or request URL.

The emailed invitation-token exchange consumes server state, so it is modeled
as a guarded TanStack mutation. Its mutation-cache state survives React Strict
Mode's effect replay, preserving the exactly-once exchange already enforced by
the frontend test.
