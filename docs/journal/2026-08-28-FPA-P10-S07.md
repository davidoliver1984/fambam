# FPA-P10-S07 — Family benchmark calibration

## Session objective

Complete ADR-0012's private recognition-calibration gate, accept a named
threshold profile and activate Phase 10 processing only as a separate final
operational step.

## Work completed

- Built a localhost-only, gitignored annotation workflow with stable detected
  face indices, anonymous identities, corrections, deliberate unknown/skip
  states, private age/coverage notes, atomic JSON writes and validation.
- Expanded the private benchmark to 79 images, 174 detected faces, 130 labelled
  faces, 20 anonymous identities and 68 labelled scene groups. All requested
  cross-age, sibling, parent/child, scan, appearance, profile and occlusion
  coverage is present; zero detected faces remain unreviewed.
- Added a duplicate-aware, leave-one-scene-group-out calibration harness that
  mirrors production gallery aggregation and deterministic complete-link
  clustering while keeping embeddings and per-face scores in memory only.
- Accepted `buffalo-l-v0.7-private-family-v1`: clustering and strong cosine
  distance `0.350`, shortlist distance `0.685`, ambiguity margin `0.300`, and
  two minimum references for a strong suggestion.
- Recorded 33 correct and zero incorrect strong suggestions across 122 trials;
  complete-link clustering produced 26 correct and zero incorrect clustered
  pairs. A 0.025 buffer separates both automatic-decision thresholds from the
  nearest observed wrong-identity match.
- Bound thresholds to the named profile, added fail-closed unknown-profile
  guards, retained the tracked disabled default, then explicitly activated the
  accepted profile in the private local environment. Recognition consent stays
  opt-in and strong suggestions remain pending human review.

## Privacy boundary

The private assets, annotations and aggregate calibration report remain under
`.local/` and are ignored by Git. No image, embedding, per-face distance,
family name or anonymous identity label is committed. The repository records
only aggregate evidence and the accepted operational thresholds.
