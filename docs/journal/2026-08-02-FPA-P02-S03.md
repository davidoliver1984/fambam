## How the system works

An invitation-capable account issues an invitation to a normalized email. The
database stores only the SHA-256 hash of a 64-character random token. The email
link puts the raw value after `#token=`, so browsers do not send it in HTTP
request URLs. React sends it in a CSRF-protected JSON request, immediately
replaces browser history with `/accept-invitation`, and receives a separate
15-minute opaque claim whose hash is stored server-side.

Acceptance locks the claim and invitation rows. It verifies claim and invitation
expiry, takes the email exclusively from the invitation, creates a verified user,
marks the claim used and invitation accepted, and writes the audit event in one
database transaction. Resend rotates the original token on the same invitation;
resend and revoke both delete outstanding claims.

## What I learned

### Laravel and software engineering

Eloquent's enum and immutable-date casts need explicit model property types for
strict static analysis to follow transaction branches. Laravel's on-demand
notifications make it possible to email an address before a `User` exists while
keeping the raw invitation token ephemeral.

### Python and image analysis

No Python image-analysis behaviour changed in this stage.

### Security, privacy and operations

Fragments are not transmitted in HTTP request targets, which keeps the emailed
bearer token out of normal Vite/API access logs and referrer headers. The page
also declares `Referrer-Policy: no-referrer`, loads no third-party resources and
removes the fragment before collecting a password. Raw invitation and claim
tokens are never persisted; resend, revoke, expiry and acceptance invalidate the
relevant standing credentials.

## Decisions

- Use a one-time emailed token followed by a 15-minute opaque claim rather than
  retaining the emailed bearer token through form submission.
- Enforce ADR-0004's 15-character minimum at account creation now; breached-
  password screening remains in FPA-P02-S04.
- Keep `can_invite` deliberately global and temporary until Phase 3 introduces
  family membership roles.
