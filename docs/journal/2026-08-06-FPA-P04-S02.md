# FPA-P04-S02 — Family Space Person records

**Date:** 2026-08-06

**Status:** Completed — implementation and full stage gate passed

**ADR:** ADR-0006 §§1–4, §§10–11, §§13–16

## Scope

This stage implements Family-Space-local Person records, uncertain birth and
death information, independent deceased state, the minimal proposed-versus-
authoritative detail distinction, directory visibility and audit/tenant
boundaries. Account links, relationships, Family Circles and merge/correction
remain assigned to S03–S05.

## Implementation

- Added immutable ULID Person records with mutable preferred/alternate names,
  normalized uncertain dates, deceased state and bounded shared biography.
- Stored uncertain dates as a nullable sortable date anchor plus explicit
  precision while preserving the user-facing exact/month/year/decade/
  approximate/unknown value contract.
- Added provisional Member creation and bounded detail proposals. Owners and
  Administrators create or edit authoritatively and can list, approve or reject
  pending proposals; approval locks and re-validates current state.
- Added explicit tenant-scoped queries, role policies, nested ULID routes,
  meaningful tenant-aware AuditEvents and Family Space teardown integration.
- Applied forced Class C PostgreSQL RLS to People and proposals.
- Added a feature-oriented React People directory/detail surface with typed API
  functions, tenant-aware query keys, TanStack Query hooks/mutations and
  React Hook Form/Zod forms.
