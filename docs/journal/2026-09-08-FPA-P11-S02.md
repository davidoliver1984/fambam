# FPA-P11-S02 — Authorized metadata search

## Session objective

Implement the first bounded metadata-search slice with authorization applied
before matching, ranking, pagination or disclosure.

## Work completed

- Added PostgreSQL-generated `search_vector` columns for the five Phase 11
  domains and a calendar-safe generated Photo historical-date window end.
- Provisioned `pg_trgm`, GIN text indexes, bounded trigram indexes and the
  supporting historical-date index.
- Added a narrow `SearchService`, dedicated typed domain summaries and signed
  opaque per-group cursor continuation.
- Implemented Photo and Album search through their existing actor-visible
  query boundaries and PhotoStory search through actor-visible Photos.
- Kept tags relational and exposed word/date search through a feature-owned
  API module, TanStack Query hook and user-facing search page.

## Decisions

- S02 ships only Photo, Album and PhotoStory results. People, Event,
  autocomplete, combined identity filters and Discovery traversal remain S03.
- Search summaries are deliberately smaller than existing domain-controller
  payloads and preserve real domain identity.
- Cursor tokens carry sort-key values and do not require the anchor row to
  remain visible or exist.

## Verification

- The complete web, Laravel and image-analysis suites passed.
- Disposable PostgreSQL 17/pgvector coverage passed, including generated
  values and a real runtime search request through tenant context and RLS.
- Formatting, lint, type checking, foundation, documentation, contracts, JSON
  validation and `git diff --check` passed.
- The persistent local PostgreSQL migration completed successfully.
- External npm/Composer advisory retrieval was unavailable because public
  registry dependency-metadata disclosure was not authorized; dependency
  files were unchanged.

## Follow-up work

FPA-P11-S03 owns People/Event search, combined filters, authorization-scoped
autocomplete and every accepted Discovery traversal.

## Implementation and review record

AI assistance implemented and tested the accepted S02 boundary. The result
was reviewed against ADR-0013, the implementation guide and the repository's
frontend engineering standard before completion.
