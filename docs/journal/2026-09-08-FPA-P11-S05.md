# FPA-P11-S05 — Search performance and permission evidence

## Session objective

Close Phase 11 with regression evidence for calendar-safe historical search,
deterministic ranking and pagination, authorization-before-disclosure and
projected pilot-library performance.

## Work completed

- Added request-level coverage for every historical-date precision and proved
  unknown dates never fall back to upload or creation timestamps.
- Proved opaque cursor continuation remains stable when the previous anchor is
  deleted or becomes inaccessible between requests.
- Expanded Guest, Contributor and Member leak regressions across search,
  autocomplete and every implemented Discovery traversal.
- Proved search terms and matching private content do not enter operational
  request logs.
- Added PostgreSQL proof for generated search-vector boundaries, relational-only
  tag matching, fixed match-class precedence and calendar-safe stored windows.
- Exercised the planned GIN search index against a representative 2,500-Photo
  Family Space and recorded a bounded execution-time assertion.

## Decisions

- S05 added evidence only; no production search behavior or authorization rule
  changed.
- The implementation has no count or facet response surfaces, so there was no
  such endpoint to exercise or expand during this evidence-only stage.
- Performance proof uses PostgreSQL planner output and index identity rather
  than a timing assertion alone.
