# FPA-P09-S05 — Queued face-analysis pipeline

## Session objective

Implement ADR-0011's production-shaped queue and transient-object hand-off,
durable attempt lifecycle, tenant-safe raw result persistence, recovery and
teardown requirements using S04's calibrated values.

## Work completed

- Added automatic canonical-ready dispatch with race-safe logical-run reuse
  and durable attempt creation before any external publication.
- Added the checksum-verifying Python raw-SQS worker with bounded inference,
  strict provider-identity matching, write-once result delivery and safe,
  reference-only terminal messages.
- Added the Laravel raw completed/failed adapter, trusted request-ID resolver,
  identity/current-state checks, result checksum and bounds validation,
  immutable observation persistence and redelivery/late-result guards.
- Added three source queues, three DLQs, calibrated redrive/visibility values,
  a one-day lifecycle-tag backstop and production Terraform IAM separation.
- Added scheduled stale-attempt reconciliation, fresh-attempt retry up to
  three, and an explicitly Family-Space-bounded audited reprocessing command.
- Added `face-analysis` to explicit Family Space object teardown and separated
  the earlier synthetic observability traffic from the real worker queue.

## Verification

- Complete repository foundation, documentation, contract, Compose, format,
  lint, type, test and security gates passed.
- PostgreSQL 17.6 migration, forced-RLS and concurrency verification passed,
  including one run/attempt under simultaneous dispatch and fail-closed raw
  poison-message behavior.
- Persistent migration batch 33 is applied.
- A disposable ordinary ready upload completed through Laravel → requested
  SQS → Python/provider → write-once S3 result → completed SQS → Laravel and
  persisted a valid zero-face result on its first attempt. The transient
  result was removed; the disposable upload and canonical object were then
  removed.
- All source queues were empty afterward and expose the calibrated 30-second
  visibility/five-receive redrive policy. The tagged one-day lifecycle rule,
  infrastructure smoke and observability smoke passed.
